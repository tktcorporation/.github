# Email Scoring 採点基準詳細

## スコア体系

各観点は **0〜10 の減点方式**で採点する。

- **0**: リスクなし / ベストプラクティス完全準拠
- **1-3**: 軽微な懸念 / ほぼ問題なし（🟢）
- **4-6**: 中程度の懸念 / 改善推奨（🟡）
- **7-10**: 重大な懸念 / 対応必須（🔴）

---

## カテゴリ A: Promotions タブリスク

### A1. ヘッダーシグナル（重み: 高）

Gmail はメールヘッダーのパターンからメールの種別を推定する。

| スコア | 条件 |
|--------|------|
| 0 | バルク送信を示すヘッダーなし。1対1のメッセージに見える |
| +2 | `List-Unsubscribe` ヘッダーあり（バルク送信の標準的シグナル） |
| +2 | `Precedence: bulk` または `list` ヘッダーあり |
| +3 | `X-Intercom-Mailer: BroadcastMailer` 等の一斉配信を示す ESP 固有ヘッダー |
| +2 | `X-Mailgun-Tag`, `X-SES-*` 等の ESP タグが複数存在 |
| +1 | `Auto-Submitted` ヘッダーあり |

**検出パターン**:
- `X-Intercom-Mailer: BroadcastMailer` → 一斉配信確定（+3）
- `X-Intercom-Mailer: ConversationMailer` → 1対1メッセージ（+0）
- `List-Unsubscribe` + `List-Unsubscribe-Post` (RFC 8058) → バルクだがベストプラクティス準拠（+1 に減点軽減）
- `Precedence: bulk` → 明示的なバルク宣言（+2）

**上限**: 10

### A2. コンテンツ語彙（重み: 最高）

メール本文に含まれるプロモーション的な語彙を検出する。**Gmail の分類で最も影響が大きい要素**。

| カテゴリ | 語彙例 | 1語あたりの加点 |
|----------|--------|----------------|
| **キャンペーン系** | キャンペーン、抽選、応募、当選、懸賞、プレゼント企画 | +1.5 |
| **金銭系** | 無料、割引、〇%OFF、セール、お得、特別価格、クーポン | +1.5 |
| **緊急性煽り** | 期間限定、本日限り、残りわずか、今だけ、お見逃しなく | +1.0 |
| **行動促進** | 今すぐ、お急ぎ、チャンスを逃すな、要チェック | +0.5 |
| **ギフト・特典** | ギフト、特典、ボーナス、プレゼント、ご褒美 | +1.0 |
| **紹介・シェア** | 紹介キャンペーン、友達紹介、シェアで〇〇、リファラル | +1.5 |

**補正**:
- 同一カテゴリ内は最大3語までカウント（飽和）
- 製品の機能説明として自然に使われている語彙は減点（例: 「価格予測機能」の「価格」や「与信スコア機能」の「スコア」のように、金銭語彙が製品名の一部として使われている場合はカウントしない）
- 逆に、文脈的に明確にプロモーションである場合は加点（例: 「シェアで豪華賞品が当たるキャンペーン」のような、紹介施策と景品訴求が組み合わさった文言）

**上限**: 10

### A3. 件名（重み: 高）

Gmail は件名を分類の重要なシグナルとして使う。

| スコア | 条件 |
|--------|------|
| +2 | 絵文字を含む（🎉、🎁、✨ 等） |
| +1 | 絵文字が2つ以上 |
| +2 | プロモーション語彙を含む（A2 の語彙リスト参照） |
| +1 | 「？」が2つ以上連続（煽り表現） |
| +1 | 「！」が2つ以上連続 |
| +1 | 金銭に関する具体的な数値（「〇〇万円」「〇〇%OFF」等） |
| +1 | 件名が60文字超（長すぎる件名はプロモ傾向） |
| -1 | パーソナライズトークンを含む（「〇〇さん」等） |
| -1 | 件名が30文字以下でシンプル |

**上限**: 10 / **下限**: 0

### A4. HTML 構造（重み: 中）

メールの HTML 構造がマーケティングテンプレートの特徴を持つか。

| スコア | 条件 |
|--------|------|
| +2 | HTML が 1000 行超 |
| +1 | HTML が 500 行超 |
| +3 | 画像が5枚以上（トラッキングピクセル除く） |
| +2 | 画像が3枚以上 |
| +1 | トラッキングピクセル（1x1 画像）あり |
| +2 | 幅580px / 600px のフルワイドバナー画像が複数 |
| +1 | テーブルネスト3段以上（典型的なメールテンプレート構造） |
| -1 | プレーンテキスト部（multipart/alternative の text/plain）が充実 |

**上限**: 10

### A5. リンク（重み: 中）

リンクの数・種類・トラッキング状況。

| スコア | 条件 |
|--------|------|
| +2 | リンク総数が15以上 |
| +1 | リンク総数が10以上 |
| +2 | 全リンクのうちトラッキング URL が80%以上 |
| +1 | 全リンクのうちトラッキング URL が50%以上 |
| +2 | CTA ボタンが4つ以上 |
| +1 | CTA ボタンが3つ |
| +1 | UTM パラメータ付き URL あり |
| +1 | 5つ以上の異なる遷移先がある（多目的メール） |

**トラッキング URL の検出パターン**:
- `*.intercom-clicks.com/*`
- `click.*` / `track.*` / `links.*` のサブドメイン
- `utm_source`, `utm_medium`, `utm_campaign` パラメータ
- SendGrid / Mailgun / SES 等の既知リダイレクトドメイン

**上限**: 10

### A6. 送信インフラ・認証（重み: 中）

メール認証と送信インフラの構成。認証が正しいことは Primary 配信を保証しないが、認証不備は Spam リスクを高める。

| スコア | 条件 |
|--------|------|
| 0 | SPF pass + DKIM pass + DMARC pass（全認証クリア） |
| +3 | DMARC fail または none |
| +2 | DKIM fail |
| +2 | SPF fail |
| +1 | From ドメインと Return-Path ドメインが異なる（第三者送信） |
| +1 | From ドメインと DKIM 署名ドメインが異なる |
| +2 | 送信元 IP がブラックリスト常連の IP レンジ（既知の場合のみ） |

**補正**:
- 第三者送信（ESP 経由）は一般的なので +1 に留める
- DMARC alignment が通っていれば第三者送信の減点を打ち消す

**上限**: 10

## カテゴリ B: メールマーケティング品質

### B1. コピーライティング（重み: 高）

件名と本文のコピーライティング品質。

| スコア | 条件 |
|--------|------|
| +2 | 件名が内容と乖離している（クリックベイト） |
| +2 | CTA のラベルが曖昧（「こちら」「詳細」のみ）|
| +1 | CTA のラベルにアクション動詞がない |
| +2 | 本文の主題が不明確（複数のトピックが並列で何のメールか分かりにくい） |
| +1 | プレヘッダーテキストが未設定または意味のない文字列 |
| +1 | 件名と本文冒頭の内容が繋がっていない |
| +1 | 送信者名が組織名のみで個人名がない（1対1感の欠如）|

**良い兆候（減点）**:
- -1: 件名が本文の核心を的確に表している
- -1: CTA が「〇〇をみてみる」「〇〇を始める」等の具体的アクション

**上限**: 10 / **下限**: 0

### B2. パーソナライズ（重み: 中）

受信者に「自分宛て」と感じさせる要素。

| スコア | 条件 |
|--------|------|
| +3 | パーソナライズ要素が一切ない（名前、固有データなし） |
| +2 | 名前だけのパーソナライズ（「〇〇さん」のみ） |
| +2 | 明らかに全員同一の内容（セグメント感なし） |
| +1 | 「あなた」「お客様」等の汎用表現のみ |

**良い兆候（減点）**:
- -2: ユーザー固有のデータが本文に反映（スコア、活動履歴、推薦情報等）
- -1: 受信者の行動・状態に基づくトリガー送信と推測できる内容

**上限**: 10 / **下限**: 0

### B3. モバイル対応（重み: 中）

モバイルでの閲覧体験。メール開封の60%以上はモバイルデバイス。

| スコア | 条件 |
|--------|------|
| +3 | `<meta name="viewport">` なし、かつ固定幅レイアウト |
| +2 | 画像幅が600pxを超えるものがある（モバイルではみ出し） |
| +2 | フォントサイズ指定が12px未満（モバイルで読みにくい） |
| +1 | CTA ボタンのタップターゲットが小さい（高さ30px未満と推測される場合） |
| +1 | `@media` クエリなし（レスポンシブ非対応） |
| +1 | 横スクロールが必要と推測されるレイアウト |

**良い兆候（減点）**:
- -1: `max-width` + `width: 100%` のフルード画像
- -1: `@media` クエリでモバイル用スタイル定義

**上限**: 10 / **下限**: 0

### B4. 配信停止・コンプライアンス（重み: 高）

法的要件と受信者の権利への配慮。

| スコア | 条件 |
|--------|------|
| +4 | 配信停止リンクが本文に見つからない |
| +2 | 配信停止リンクが極端に小さいフォント / 薄い色で視認しにくい |
| +1 | 配信停止リンクがフッター最下部にしかない |
| +3 | `List-Unsubscribe` ヘッダーなし（RFC 8058 非準拠） |
| +2 | `List-Unsubscribe-Post` なし（ワンクリック解除非対応） |
| +1 | 送信元の物理住所がない（CAN-SPAM 要件） |
| +1 | 送信元の会社名/サービス名が不明確 |

**補正**:
- 日本国内向けメールの場合、特定電子メール法の要件（送信者名、連絡先、配信停止方法の明示）も確認

**上限**: 10 / **下限**: 0

### B5. エンゲージメント設計（重み: 高）

受信者が開封→読了→クリック→コンバージョンに至る導線設計。

| スコア | 条件 |
|--------|------|
| +2 | CTA が6つ以上（選択肢過多で分散） |
| +2 | 主要 CTA が fold below（スクロールしないと見えない位置）にある |
| +2 | メールの目的が不明確（通知なのかプロモなのか混在） |
| +1 | 情報の優先度が不明確（重要な情報が後半に埋もれている） |
| +1 | メール長が過剰（スクロール5回以上相当） |
| +1 | CTA ボタンのコントラストが低い / 目立たない |
| +1 | 複数の無関係なトピックが1通に詰め込まれている |

**良い兆候（減点）**:
- -1: 明確な1つの主要 CTA がある
- -1: 逆ピラミッド構造（結論 → 詳細 → CTA の順）
- -1: 情報の優先度が視覚的に明確（見出し、余白、強調）

**上限**: 10 / **下限**: 0

## 総合判定

### Promotions タブリスク（A カテゴリ合計 / 60）

| スコア帯 | リスクレベル | 解釈 |
|----------|-------------|------|
| 0-12 | **低** | Primary に届く可能性が高い |
| 13-24 | **中** | ボーダーライン。ユーザーのエンゲージメント次第 |
| 25-40 | **高** | Promotions に分類される可能性が高い |
| 41-60 | **非常に高い** | ほぼ確実に Promotions（または Spam リスクも） |

### メールマーケティング品質（B カテゴリ合計 / 50）

| スコア帯 | 品質レベル | 解釈 |
|----------|-----------|------|
| 0-10 | **優秀** | ベストプラクティス準拠。強い改善点なし |
| 11-20 | **良好** | 基本を押さえているが改善余地あり |
| 21-35 | **改善余地あり** | 複数の重要な改善ポイントがある |
| 36-50 | **要改善** | 基本的な要件を満たしていない |
